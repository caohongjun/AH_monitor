# AH Monitor · 今日热榜 & A/港股舆情监控看板

全免费、无服务器的信息聚合看板。GitHub Actions 每天定时运行 Python 爬虫，抓取各平台热榜、科技资讯和 A/港股财经快讯，生成静态页面并发布到 GitHub Pages。

- **线上地址**：<https://caohongjun.github.io/AH_monitor/>
- **技术栈**：Python 3.12（Requests / BeautifulSoup）+ GitHub Actions + GitHub Pages + Tailwind CSS CDN
- **运行成本**：0 元。无服务器、无数据库、无需任何 API Key

## 页面一览

每次构建生成两个页面，顶部导航可互相切换：

| 页面 | 文件 | 内容 |
|------|------|------|
| 🔥 今日热榜（首页） | `index.html` | 社会舆情 / 科技动态 / 游戏与产品三个板块，共 16 个信息源模块 |
| 📈 财经与股市 | `finance.html` | A/港股负面与突发舆情监控、今日要点、自选标的行情 |

所有页面支持深色/浅色主题切换（自动记忆），导航右侧有 GitHub Actions 入口，数据没及时更新时可以手动触发构建。

## 构建与更新时间

- 每天**北京时间 09:30 和 18:00**各自动构建一次（UTC 01:30 / 10:00，见 `.github/workflows/deploy.yml`）。
- GitHub Actions 的定时任务通常会延迟 0~30 分钟，属正常现象。
- 也可以随时手动构建：仓库 **Actions → Deploy Dashboard → Run workflow**。
- 页面上显示的「数据更新时间」就是本次构建时间。两次构建之间页面内容不会变化。
- 所有日期判断都按**北京时间**计算，「今天」指构建当天的北京时间日期。

## 数据更新规则

### 时间规则说明

每个信息源的更新频率不同，所以各自配置独立的时间规则（`config.py` 中的 `SOURCE_RULES`）：

| 规则 | 含义 |
|------|------|
| **当天优先** `today_yesterday` | 当天有内容只展示当天；当天没有才展示前一天；前一天也没有则模块为空。不会展示更早的内容 |
| **今昨合并** `today_and_yesterday` | 同时展示今天和昨天的内容，今天在前；两天都没有则模块为空 |
| **近 N 天** `recent_7d` | 展示最近 7 天内发布的内容，适合周更的低频源 |
| **最新一天** `latest_day` | 不限定今天或昨天。抓到的内容里最新是哪一天，就只展示那一天 |  
| **实时榜单** `realtime` | 直接取构建时刻的榜单快照，不按日期过滤 |

没有发布时间、无法判断日期的条目，在「当天优先」「今昨合并」和「最新一天」规则下会直接丢弃。每个模块的条数上限也在 `SOURCE_RULES` 中单独配置，超出模块高度时在模块内部滚动。

每个模块右上角显示该模块最新一条数据的时间。头条、微博、百度、Reddit、GitHub Trending 这类榜单没有单条发布时间，右上角仍显示本次抓取时间。

### 财经与股市页

| 板块 | 更新规则 |
|------|----------|
| 快讯来源 | 东方财富、证券时报、新浪 7x24、华尔街见闻、金十数据、新浪滚动、每日经济新闻共 7 个来源，**只保留北京时间当天**的快讯。单个来源失败不影响其他来源 |
| 今日要点 | 从当天快讯中按要闻词库打分筛选，分国内 / 海外两组，各展示 6 条；已进入负面事件的快讯不重复展示 |
| 负面舆情概览 | 跌幅榜 Top 5、事件类型分布、重点事件 Top 5（按命中标签数、跌幅和高危标签综合打分） |
| 重点关注 | 自选标的的实时行情；每个标的优先展示相关负面事件，没有时展示最新相关快讯，最多 3 条 |
| 事件列表 | 命中负面/突发词库的当天快讯，按时间倒序，最多 100 条；同一标题和标的只保留一条 |
| 行情 | 构建时通过腾讯财经接口拉取现价和涨跌幅，跌幅超过 3% 红色高亮 |

负面/突发词库分为 7 组：监管调查、诉讼纠纷、传闻辟谣、举报公关、经营风险、高管异动、股价异动。股票代码优先使用数据源自带的结构化标的，其次从正文中正则识别（A 股 6 位代码、港股 5 位代码、`.SH` `.SZ` `.BJ` `.HK` 等后缀），识别不到的事件归为「未识别」。

页面支持按市场（A 股 / 港股 / 未识别）筛选、关键词标签多选和全文搜索；页脚显示每个来源本次的抓取数和命中数。

## 本地运行

需要 Python 3.10 及以上版本（线上使用 3.12）：

```bash
pip install -r requirements.txt
python crawler.py
```

运行完成后会在项目根目录生成 `index.html` 和 `finance.html`，用浏览器直接打开即可。完整运行大约需要 2~3 分钟，其中微信公众号为了避开搜狗风控，请求之间会主动等待。

生成的 HTML 已加入 `.gitignore`，不需要提交到仓库，线上页面由 GitHub Actions 构建后直接发布。

## 部署

仓库已配置好 GitHub Actions 自动部署，代码合并到 `main` 后，下一次定时构建就会生效；想立即生效可以手动运行一次 **Deploy Dashboard**。

如果要在新仓库中部署：

1. 推送本项目全部文件到新的 GitHub 仓库。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**（工作流也会尝试自动启用）。
3. 在 **Actions → Deploy Dashboard → Run workflow** 手动运行一次。
4. 访问 `https://<用户名>.github.io/<仓库名>/`。
5. 把 `render.py` 中 `_nav_extras` 里的 GitHub Actions 链接改成新仓库地址。

## 目录结构

```text
├── .github/workflows/deploy.yml   # 定时构建 + 发布到 GitHub Pages
├── crawler.py                     # 入口：抓取 → 加工 → 渲染 → 写出两个页面
├── config.py                      # 配置：各源时间规则与条数、词库、自选标的
├── utils.py                       # 工具：HTTP 会话、时间解析、去重、时间规则过滤
├── spiders.py                     # 抓取：财经快讯、行情、热榜和各资讯源
├── processor.py                   # 加工：标的识别、负面词命中、事件组装、今日要点、自选标的
├── render.py                      # 渲染：今日热榜页、财经与股市页
├── requirements.txt               # Python 依赖
└── README.md
```

## 常见修改

| 想改什么 | 改哪里 |
|----------|--------|
| 某个模块的时间规则或条数 | `config.py` → `SOURCE_RULES` |
| 负面/突发词库 | `config.py` → `KEYWORD_GROUPS` |
| 今日要点词库 | `config.py` → `MARKET_CORE_KEYWORDS`、`MARKET_KEYWORDS`、`MARKET_DOMESTIC_KEYWORDS`、`MARKET_GLOBAL_KEYWORDS` |
| 自选关注标的 | `config.py` → `WATCHLIST` |
| 财经事件条数上限 | `config.py` → `MAX_EVENTS`（默认 100） |
| 关注的微信公众号 | `spiders.py` → `_WECHAT_ACCOUNTS` |
| 新增今日热榜模块 | 在 `spiders.py` 写抓取函数并加到 `build_hotboard_data`；在 `config.py` 的 `SOURCE_RULES` 配置规则；在 `render.py` 的 `_SOURCE_FAVICON`、`_SOURCE_HOME` 配置图标和链接 |
| 新增财经快讯来源 | 在 `spiders.py` 写抓取函数并加到 `SOURCE_REGISTRY`（顺序即同稿去重时的优先级） |
| 构建时间 | `.github/workflows/deploy.yml` 中的 cron（填 UTC 时间），并同步修改页面上显示的时间文案 |
